# Release Package Manifest v1.0

This manifest describes the curated public upload archive:

`publication/wearable-performance-case-study-v1.0-release.zip`

## Included

- Final manuscript: Markdown, DOCX, and PDF.
- Final publication figures and tables.
- Derived analysis CSV files required to reproduce the manuscript findings.
- Statistical, HRV/RHR, FIDAL import, screenshot-integration, and methodology reports.
- Reproducibility scripts and exploratory notebook.
- GitHub, Zenodo, and OSF metadata/checklists.
- README, MIT license, citation metadata, and release notes.

## Excluded

- Raw Garmin export folders.
- Raw route/GPS files such as FIT, TCX, and GPX.
- Manual screenshot image files in `data/manual_screenshots/`.
- Old manuscript drafts and school-summary drafts.
- The Garmin export inventory CSV, because it describes private Garmin export internals and is not required for the public release package.
- The ZIP archive itself.

## Notes

Screenshot-derived HRV/RHR CSV files are included because they document the secondary audit, but they are explicitly marked as approximate and are excluded from the primary statistical analysis.
